# HEXAI Telemetry - Next.js & Tailwind CSS

High-performance athletic telemetry and tactical intelligence web platform engineered for elite front offices, collegiate scouts, and pro franchises.

## 🏀 Core Application Pages

### 1. Landing & Telemetry Overview (`/`)
- **Hero Viewport**: Real-time optical telemetry HUD overlays, frame precision sync indicators, mid-air apex trajectory trackers, and verified player telemetry snapshots.
- **Three Stakeholder Pillars**:
  - **Athletes**: Player trajectory, shot arc consistency progress bar, telemetry drills linked.
  - **Coaches**: 1-click film tagging with interactive tag toggles (`PnR Defense`, `Corner 3 C&S`, `Box Out`).
  - **Scouts**: NCAA-compliant verified recruiting intelligence, coach-mediated messaging.
- **4-Step Architecture**: Build Your Profile → Upload Game Film → Analyze Performance → Improve with Purpose.
- **Interactive 4-Module Showcase**:
  - **Player Dashboard**: Interactive SVG half-court shot matrix with real-time zone telemetry inspection on hover.
  - **Video Workspace**: Telestration drawing paths, interactive play/pause scrub bar, and timestamp markers.
  - **Vance-LLM AI Coach**: Dynamic tactical feedback engine supporting 4 coaching dispositions (*Supportive*, *Balanced*, *Direct*, *Demanding*).
  - **Scout Comparison Engine**: Side-by-side prospect evaluation matrices with compliant metrics.
- **Compliance & Security**: SOC-2 Type II, FERPA / COPPA protocols, and tamper-proof verification banner.
- **Interactive Modals**:
  - Role-based onboarding & sign-in modal (`Athlete`, `Coach`, `Scout`).
  - 1080p60 game film ingest terminal simulator with optical jersey detection and possession segmentation.

### 2. Sign Up & Persona Assignment (`/sign-up`)
- **Step 01 Persona Assignment**: Athlete (Player Hub), Coach / Staff (Roster Hub), and College / Pro Scout (Scouting Matrix) cards with dynamic attributes.
- **Live Console Telemetry Card**: 120 FPS capture rate, 3D volume shot vectors, 14ms AI latency.
- **Step 02 Profile Credentials**: Google and Apple OAuth, manual verification, and dynamic role-specific fields (Grad class, Jersey #, Team code, Division, etc.).
- **Interactive Password Criteria**: Real-time validation indicators for 8+ characters, 1+ number, and 1+ symbol.

### 3. Sign In Operating Console (`/sign-in`)
- **Operating Console Switcher**: Toggle between Athlete, Coach / Staff, and Verified Scout consoles with live UI updates and active badges.
- **Enterprise SSO Connectors**: Direct Hudl • Synergy SSO institutional button, plus Google Workspace and Apple ID quick-connect.
- **Live Visual Feed**: High-contrast basketball action shot with optical telemetry overlays, HUD FPS badge (120 FPS), and player card snapshot.
- **Tactical Data Strip**: Live session metric blocks (PPG Avg, Release Speed, Vault Sync), recent ingest notification, and interactive mini court hotzone visualizer SVG.
- **NCAA Compliance Badge**: Zero-knowledge identity vault verification.

## 🚀 Getting Started

### 1. Install Dependencies
```bash
npm install
```

### 2. Start Development Server
```bash
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) in your browser.

### 3. Production Build
```bash
npm run build
npm start
```
